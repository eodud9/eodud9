# 안녕하세요 👋

안녕하세요, 김대영입니다.  
제가 가진 기술로 사람들의 하루에 더 많은 웃음을 더하는 개발자를 지향합니다.

단순히 코드를 작성하는 것을 넘어, **사람들에게 필요한 문제를 발견하고 기술로 해결하며 세상에 기여하는 일**에 가치를 두고 있습니다.  
현재의 방식에 머무르기보다 더 나은 방법과 새로운 가능성을 고민하고, 아이디어를 실제로 구현하는 데 필요한 기술이라면 주저하지 않고 배우고 도전합니다.
